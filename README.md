# Expense Tracker 💰

A simple and responsive web-based Expense Tracker built using HTML, CSS, and JavaScript.

## Features

- Add new expenses
- Select expense categories
- View expense history
- Calculate total expenses automatically
- Delete expenses
- Save expenses using browser localStorage
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- GitHub Pages

## How It Works

Users can enter an expense name, amount, and category. The application displays the expense in the expense history and automatically updates the total amount.

Expenses are stored in the browser using LocalStorage, so the data remains available even after refreshing the page.
